Delegated cgroup v2 resource gate. Opt-in experiment requiring a delegated cgroup subdirectory under /sys/fs/cgroup. Writes and reads memory.max and cpu.max, places a fixed trusted sleep process, and cleans up. It refuses the root hierarchy and arbitrary filesystem paths. GitHub Actions does not create or delegate privileged cgroups: NOT_DELEGATED is an expected observation, not evidence of enforced limits. The probe never authorizes arbitrary application execution. See https://www.kernel.org/doc/html/latest/admin-guide/cgroup-v2.html
