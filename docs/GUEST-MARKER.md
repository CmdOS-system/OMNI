# Guest serial marker protocol v1 (untrusted)

The guest can emit a single line `OMNI_GUEST_BOOT_V1 {"nonce":"<32 lowercase hex>","kernel":"Linux ..."}` on its serial console. `vm/guest_marker.py` validates the line, nonce and bounded log size. A matching nonce is **not proof** that the guest booted: host-side scripts, compromised QEMU or malicious disk contents can forge the marker. No attestation key, TPM quote, measured boot or independent observer exists yet. The nonce must be generated by a trusted external orchestrator and delivered to the guest securely. This module is a protocol parser only and is not yet wired into `vm/capture.py`.
