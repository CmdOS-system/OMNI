OMNI Preview for Windows: graphical, read-only format explorer. Run python -m omni.windows_preview or download the OMNI-Preview-Windows artifact from GitHub Actions. PyInstaller produces a single EXE. No installer required. This build does NOT run apps, certify compatibility, or sandbox unknown files. Windows path validation is best-effort (reparse-point check) and not a security boundary against concurrent path changes. Do not use this preview to inspect hostile paths in a shared directory.
